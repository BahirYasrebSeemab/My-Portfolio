# My Portfolio

A personal portfolio site built with React and Vite, using Bun as the package manager.

## Getting Started

Install dependencies:

```bash
bun install
```

Run the dev server:

```bash
bun run dev
```

Build for production:

```bash
bun run build
```

Preview the production build locally:

```bash
bun run preview
```

Lint the project:

```bash
bun run lint
```
